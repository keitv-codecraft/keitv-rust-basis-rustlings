# KeiTV Rustlings

Kleine Rust-oefeningen in eenvoudig Nederlands. De oefeningen zijn per
artikel gegroepeerd en gebruiken games als rode draad.

## Starten

Installeer [Rustlings volgens de officiële instructies](https://github.com/rust-lang/rustlings). Clone daarna [deze repository](https://github.com/keitv-codecraft/keitv-rust-basis-rustlings) en voer uit:

```text
rustlings
```

Voor controles vanuit de repository:

```text
rustlings dev check
```
